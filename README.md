# Tout Dans l'Agenda (TDA)

Une application web simple pour organiser ses tâches, pensée pour les personnes concernées par le TDA(H) et conçue avec une psychologue.

👉 **Ouvrir l'appli : <https://madix-sanzeu.github.io/Tout-Dans-L-Agenda/>**

- Une seule tâche mise en avant : « Maintenant ».
- Tri automatique selon la matrice d'Eisenhower, d'après l'article [« Comment prioriser ses tâches avec un TDAH »](https://le-tdah-au-quotidien.com/comment-prioriser-ses-taches-avec-un-tdah/).
- Moments de vie (travail, perso…) pour ne voir que ce qui compte maintenant.
- Rappel obligatoire pour chaque tâche, même appli fermée (option).
- Découpage en étapes, durée avec marge, aucune inscription : les tâches restent sur le téléphone.

Documentation : [GUIDE.md](GUIDE.md) (fonctionnement du code), [DEPLOIEMENT.md](DEPLOIEMENT.md) (mise en ligne), [RELAIS.md](RELAIS.md) (avancement).

Un avis, un bug ? [Ouvrir une demande](https://github.com/Madix-Sanzeu/Tout-Dans-L-Agenda/issues/new).

_Tout Dans l'Agenda n'est pas un dispositif médical et ne remplace pas l'accompagnement d'un professionnel de santé._
