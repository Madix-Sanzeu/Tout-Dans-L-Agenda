Confidentialité

Dernière mise à jour : 23 novembre 2026.

En résumé

  • Vos tâches sont enregistrées uniquement sur votre appareil.
  • Pas de compte, pas d'email, pas de publicité, pas de mesure d'audience, pas de cookies.
  • Seule exception, si vous l'activez : l'option « Rappels même appli fermée » envoie l'heure (et, si vous le souhaitez, le titre) de vos rappels à venir à notre serveur, le temps de vous les envoyer.

Les données qui restent sur votre appareil

Tâches, étapes, échéances, moments de vie et réglages sont stockés dans la mémoire de votre navigateur (« localStorage »). Nous n'y avons pas accès. Vous pouvez les exporter, les importer ou les effacer à tout moment (en effaçant les données du site dans votre navigateur).

Base légale : votre consentement, donné en activant l'option. Vous pouvez le retirer à tout moment avec le bouton « Désactiver et effacer mes données du serveur » : tout ce qui concerne votre appareil est alors immédiatement supprimé.

⚠️ Le titre d'une tâche peut contenir des informations personnelles, y compris sur votre santé (« Rendez-vous psychiatre »). Si vous ne souhaitez pas qu'il quitte votre téléphone, cochez « Masquer les titres ».

Qui traite ces données ?

  • Supabase héberge notre serveur et sa base de données, dans un centre de données situé dans l'Union européenne.
  • Le service de notifications de votre navigateur (Google pour Chrome/Android, Apple pour Safari/iPhone, Mozilla pour Firefox) achemine la notification. Son contenu est chiffré : seul votre appareil peut le lire.

Aucune donnée n'est vendue ni partagée à d'autres fins.

Vos droits

Vous disposez d'un droit d'accès, de rectification, d'effacement et d'opposition. Comme nous ne savons pas qui vous êtes, le plus simple est d'utiliser le bouton de désactivation dans l'appli. Vous pouvez aussi nous contacter (voir ci-dessous) ou adresser une réclamation à la CNIL (cnil.fr).

Contact

Responsable du traitement : l'éditeur de l'appli (voir les mentions légales). Contact : via la page du projet sur GitHub.
